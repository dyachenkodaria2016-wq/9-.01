# Access Lab — навчальний симулятор баз даних

Статичний HTML-проєкт для GitHub Pages. Не потребує платних сервісів, серверної бази даних або npm-залежностей.

## Що реалізовано
- Навчальні таблиці «Учні» та «Оцінки».
- Додавання записів і створення простих таблиць.
- Конструктор запитів з вибором будь-якого поля, операторів, AND/OR.
- Порівняння текстових, числових і датованих значень.
- JSON-резервна копія з імпортом назад у симулятор.
- Експорт поточної таблиці та всіх таблиць у CSV.
- Імпорт CSV у вибрану таблицю.
- Вбудована інструкція українською.

## Важливо щодо Microsoft Access
Сайт не генерує справжні файли `.accdb`. Це пропрієтарний формат Microsoft Access; не можна просто перейменувати CSV або JSON на `.accdb`. Для обміну передбачено CSV. Імпортуйте CSV у Microsoft Access через **Зовнішні дані → З файлу → Текстовий файл**, вкажіть роздільник **крапка з комою**, текстовий обмежувач **"**, та прапорець **Перший рядок містить імена полів**. Після імпорту збережіть базу у форматі `.accdb` безпосередньо в Access.

CSV переносить значення полів, але не створює автоматично зв'язки, первинні ключі, форми, запити або звіти. Їх потрібно налаштувати в Access окремо. JSON зберігає структуру для цього симулятора, а не для Microsoft Access.

## Публікація на GitHub Pages
1. Створіть репозиторій GitHub.
2. Завантажте в корінь репозиторію `index.html`, `README.md` і папку `.github`.
3. Зробіть Commit у гілку `main`.
4. Відкрийте **Actions** і дочекайтеся зеленого статусу workflow `Deploy to GitHub Pages`.
5. Відкрийте **Settings → Pages**. Джерело розгортання має бути `GitHub Actions`.
6. Перейдіть за адресою `https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПОЗИТОРІЮ/`.

## Перевірка перед уроком
1. Відкрийте «Таблиці», виберіть «Учні».
2. У конструкторі запитів перевірте, наприклад, `Прізвище` → `містить` → `енко`.
3. Перевірте `Клас` → `дорівнює` → `9-А`.
4. Перевірте числове поле `Оцінка` → `більше` → `9`.
5. Експортуйте JSON, оновіть сторінку й імпортуйте JSON назад.
6. Експортуйте CSV і перевірте імпорт у Microsoft Access.

## Обмеження поточної навчальної версії
- Дані в пам'яті сторінки скидаються після перезавантаження, якщо не експортувати JSON.
- Це симулятор базових операцій, не повна реалізація Microsoft Access або SQL.
- Вкладені форми, звіти, повноцінні зв'язки таблиць та створення `.accdb` не реалізовані.
